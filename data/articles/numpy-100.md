Это сборник упражнений. Их собрали из рассылки NumPy, со Stack Overflow и из документации NumPy. Цель — дать быстрый справочник новым и опытным пользователям, а также набор задач для преподавателей.

Звёзды показывают сложность: ★☆☆ — простое, ★★☆ — среднее.

Как работать: решайте в Jupyter или в Python. Если застряли, посмотрите подсказку под задачей. Решения — в файле [100_Numpy_exercises_with_solutions.md](https://github.com/rougier/numpy-100/blob/master/100_Numpy_exercises_with_solutions.md) в репозитории (код там понятен без перевода).

## Упражнения 1–20

**1.** Импортируйте пакет numpy под именем `np`. (★☆☆)
Подсказка: `import … as`

**2.** Выведите версию numpy и её конфигурацию. (★☆☆)
Подсказка: `np.__version__`, `np.show_config()`

**3.** Создайте нулевой вектор размера 10. (★☆☆)
Подсказка: `np.zeros`

**4.** Как узнать, сколько памяти занимает массив? (★☆☆)
Подсказка: `size`, `itemsize`

**5.** Как получить документацию функции `add` из numpy в командной строке? (★☆☆)
Подсказка: `np.info`

**6.** Создайте нулевой вектор размера 10, где пятое значение равно 1. (★☆☆)
Подсказка: `array[4]`

**7.** Создайте вектор со значениями от 10 до 49. (★☆☆)
Подсказка: `arange`

**8.** Разверните вектор: первый элемент становится последним. (★☆☆)
Подсказка: `array[::-1]`

**9.** Создайте матрицу 3×3 со значениями от 0 до 8. (★☆☆)
Подсказка: `reshape`

**10.** Найдите индексы ненулевых элементов в `[1, 2, 0, 0, 4, 0]`. (★☆☆)
Подсказка: `np.nonzero`

**11.** Создайте единичную матрицу 3×3. (★☆☆)
Подсказка: `np.eye`

**12.** Создайте массив 3×3×3 со случайными значениями. (★☆☆)
Подсказка: `np.random.random`

**13.** Создайте массив 10×10 со случайными значениями и найдите минимум и максимум. (★☆☆)
Подсказка: `min`, `max`

**14.** Создайте случайный вектор размера 30 и найдите среднее. (★☆☆)
Подсказка: `mean`

**15.** Создайте двумерный массив: 1 по краям, 0 внутри. (★☆☆)
Подсказка: `array[1:-1, 1:-1]`

**16.** Как добавить вокруг существующего массива рамку из нулей? (★☆☆)
Подсказка: `np.pad`

**17.** Чему равны выражения? (★☆☆)

```python
0 * np.nan
np.nan == np.nan
np.inf > np.nan
np.nan - np.nan
np.nan in set([np.nan])
0.3 == 3 * 0.1
```

Подсказка: NaN — «не число» (not a number), inf — бесконечность.

**18.** Создайте матрицу 5×5, где значения 1, 2, 3, 4 стоят сразу под диагональю. (★☆☆)
Подсказка: `np.diag`

**19.** Создайте матрицу 8×8 и заполните её в шахматном порядке. (★☆☆)
Подсказка: `array[::2]`

**20.** Дан массив формы (6, 7, 8). Какой индекс (x, y, z) у 100-го элемента? (★☆☆)
Подсказка: `np.unravel_index`

## Упражнения 21–40

**21.** Создайте шахматную матрицу 8×8 функцией `tile`. (★☆☆)
Подсказка: `np.tile`

**22.** Нормализуйте случайную матрицу 5×5. (★☆☆)
Подсказка: `(x - mean) / std`

**23.** Создайте свой `dtype`, который описывает цвет как четыре байта без знака (RGBA). (★☆☆)
Подсказка: `np.dtype`

**24.** Умножьте матрицу 5×3 на матрицу 3×2 (настоящее матричное произведение). (★☆☆)
Подсказка: оператор `@` или `np.dot`.

**25.** Дан одномерный массив. Поменяйте знак у всех элементов от 3 до 8 прямо в массиве (на месте). (★☆☆)
Подсказка: `>`, `<`

**26.** Что выведет скрипт? (★☆☆)

```python
# Автор: Jake VanderPlas

print(sum(range(5), -1))
from numpy import *
print(sum(range(5), -1))
```

Подсказка: `np.sum`

**27.** Дан целочисленный вектор `Z`. Какие выражения допустимы? (★☆☆)

```python
Z**Z
2 << Z >> 2
Z <- Z
1j*Z
Z/1/1
Z<Z>Z
```

**28.** Чему равны выражения? (★☆☆)

```python
np.array(0) / np.array(0)
np.array(0) // np.array(0)
np.array([np.nan]).astype(int).astype(float)
```

**29.** Как округлить массив дробных чисел «от нуля» (вверх для положительных, вниз для отрицательных)? (★☆☆)
Подсказка: `np.random.uniform`, `np.copysign`, `np.ceil`, `np.abs`, `np.where`

**30.** Как найти общие значения двух массивов? (★☆☆)
Подсказка: `np.intersect1d`

**31.** Как отключить все предупреждения numpy (так делать не рекомендуется)? (★☆☆)
Подсказка: `np.seterr`, `np.errstate`

**32.** Верно ли выражение? (★☆☆)

```python
np.sqrt(-1) == np.emath.sqrt(-1)
```

Подсказка: мнимое число.

**33.** Как получить даты вчера, сегодня и завтра? (★☆☆)
Подсказка: `np.datetime64`, `np.timedelta64`

**34.** Как получить все даты июля 2016 года? (★★☆)
Подсказка: `np.arange(dtype='datetime64[D]')`

**35.** Как вычислить `((A + B) * (-A / 2))` на месте, без копий? (★★☆)
Подсказка: `np.add(out=)`, `np.negative(out=)`, `np.multiply(out=)`, `np.divide(out=)`

**36.** Возьмите целую часть случайного массива положительных чисел четырьмя разными способами. (★★☆)
Подсказка: `%`, `np.floor`, `astype`, `np.trunc`

**37.** Создайте матрицу 5×5, где в каждой строке значения от 0 до 4. (★★☆)
Подсказка: `np.arange`

**38.** Напишите функцию-генератор, которая выдаёт 10 целых чисел, и постройте из неё массив. (★☆☆)
Подсказка: `np.fromiter`

**39.** Создайте вектор размера 10 со значениями от 0 до 1, сами 0 и 1 не входят. (★★☆)
Подсказка: `np.linspace`

**40.** Создайте случайный вектор размера 10 и отсортируйте его. (★★☆)
Подсказка: `sort`
